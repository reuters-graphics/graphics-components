Add LoadingStatus and LoadingDots for shared loading presentation. LoadingStatus
provides a slow-turning Kinesis mark in block and inline sizes, with an optional
visible label. LoadingDots provides three gently lifting periods for compact
placements. Both include descriptive screen-reader messages, optional parent-owned
announcements, colour controls, and static presentation for reduced motion.
