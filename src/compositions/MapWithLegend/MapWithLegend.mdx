# Map with a legend

Show map data, explain its colors, and mark where the area is.

<Canvas of={MapWithLegendStories.WildfireMap} />

The loading message sits over the map while both data files are fetched, then
disappears when they arrive. This example adds a short pause before fetching so
the message is easy to see. In your own map, remove that pause and use your data
request directly.

Keep the legend with the map and use the same colors for the key and the map
layers. This inset leaves out the Canary Islands so mainland Spain fits in the
map's top-left corner.

```svelte
<TileMap center={[-4.1, 40.4126]} zoom={8}>
  {#snippet legend()}
    <Legend mode="categorical" items={legendItems} />
  {/snippet}

  {#if loading}
    <MapStatusOverlay status="loading" message="Loading map data…" />
  {:else if error}
    <MapStatusOverlay
      status="error"
      message="Map data unavailable. Please refresh."
    />
  {:else}
    <TileMapLayer id="burned-area" {data} type="fill" paint={areaPaint} />
  {/if}

  <InsetMap
    corner="top-left"
    bounds={[-9.5, 35.8, 4, 44]}
    geometry={areaShape}
    class="thematic-map-inset"
  />
</TileMap>

<style>
  :global(.inset-map.thematic-map-inset.corner-top-left) {
    left: 7px;
    top: -12px;
  }
</style>
```
