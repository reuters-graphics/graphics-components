# Diverging

Nine-step scales for values either side of a meaningful midpoint — change, difference from average, a vote margin. Steps run from `-400` to `+400` around a shared neutral `0`, and each arm darkens evenly away from it. The two extremes match the `800` stops of the [sequential ramps](?path=/docs/styles-colours-sequential--docs). Each scale is its own import.

Blue–rust and yellow–blue are the best-separated pairs the categorical colours allow. The blue arm is the same in both, as is the yellow arm in yellow–blue and teal–yellow.
