# Sequential

Nine-step ramps for values that run from low to high, light (`100`) to dark (`900`). Every ramp darkens steadily in normal vision, under simulated deuteranopia, protanopia and tritanopia, and in greyscale. Each ramp is its own import, so a page only carries the ramps it uses.

## Single hue

One ramp per categorical colour, built to shared lightness steps so ramps of different hues line up. Each contains its categorical colour exactly: rust and teal at `500`, blue at `600`, plum and green at `700`, yellow at `400`.
